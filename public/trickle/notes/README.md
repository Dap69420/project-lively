# Vektra - Landing Page

**Vibe:** Retro-Future / Neubrutalism (Landing & Auth), Discord-Minecraft (Workspace), Glassmorphism Dark Mode (Profile)
**Target Audience:** Grade 6-9 Students
**Colors:** Dark theme, Electric Lime (`#ccff00`), Hot Pink (`#ff00ff`), Neon Violet (`#b026ff`)

## Components
- **Hero:** Impactful headline with brutalist styling.
- **Features:** 3 core differentiators of the AI study buddy.
- **Roadmap:** Vertical timeline showing phases.
- **Donation:** "Fuel the Lab" card with UPI QR placeholder.

## Pages & Features
1. **Landing Page (`index.html`)**
   - Vibe: Retro-Future / Neubrutalism
   - Hero, Features, Roadmap, Donation.
2. **Login Page (`login.html`)**
   - Gateway between Landing Page and Workspace.
   - Vibe: Neubrutalism matching the Landing Page.
   - Toggle between Login and Sign Up.
3. **Workspace Dashboard (`workspace.html`)**
   - Vibe: Discord-meets-Minecraft (Dark themes, Neon accents, rounded corners).
   - Header with XP Bar and Streak Counter.
   - Split-screen "Duo-Mode" (Mission Card & AI Chat).
   - "Explain Box" and Mood Orb in AI Chat.
   - Resource Sidebar with Notes and Canvas-based Sketchpad.
4. **User Evolution Profile (`profile.html`)**
   - Vibe: Dark mode, glassmorphism panels, neon violet accents.
   - Avatar placeholder for a 3D-style character.
   - Stats Grid showing Brain Power, Sync Streak, Concepts Taught, and Ranks.
   - Vertical Skill Tree for subject progression.
   - Horizontal scrolling list of Recent Badges.

## Tech Stack
- React 18
- TailwindCSS (Custom variables per HTML file to handle multiple aesthetics)
- Lucide Icons (Static CSS approach)
- Supabase (Google OAuth Authentication)
